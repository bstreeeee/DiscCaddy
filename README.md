# DiscCaddy

DiscCaddy is a single-page disc golf companion app. It currently runs from a standalone `index.html` file and stores data locally in the browser with `localStorage`.

## Run locally

Open `index.html` in a browser.

## Notes

- Data is saved on the device and browser where the app is used.
- Tailwind is loaded from the CDN, so the first load needs internet access.
- The current app is bundled into one HTML file, which is a good baseline for publishing while future development can move toward a source-based project structure.
